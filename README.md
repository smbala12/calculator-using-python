# 🧮 Python Calculator

A simple command-line calculator built with Python that performs basic arithmetic operations.

---

## 📌 Features

The calculator allows the user to:

- Add two numbers (`+`)
- Subtract two numbers (`-`)
- Multiply two numbers (`*`)
- Divide two numbers (`/`)

It prompts the user to:

1. Enter a mathematical operation.
2. Enter two numbers.
3. Displays the calculated result rounded to 2 decimal places.
4. Handles invalid operations with an error message.

---

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Save the file as `calculator.py`
3. Open a terminal or command prompt.
4. Run:

```bash
python calculator.py
